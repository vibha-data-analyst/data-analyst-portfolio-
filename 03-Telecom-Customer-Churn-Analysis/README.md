# Telecom Customer Churn Analysis

## Project Overview

This project analyzes customer churn in a telecommunications company using Tableau Public. The main purpose is to understand customer churn patterns and identify the factors associated with customers leaving the company.

An interactive dashboard was created to present key performance indicators (KPIs) and customer churn analysis through visualizations.

## Project Objectives

- Analyze the overall customer churn rate.
- Identify which contract types have higher churn rates.
- Understand churn patterns across internet services.
- Analyze churn based on monthly charges and customer tenure.
- Explore churn patterns by payment method and customer demographics.
- Present insights through a Tableau dashboard.

## Tools Used

- Tableau Public
- Telco Customer Churn Dataset

## Key Performance Indicators (KPIs)

| KPI | Result |
|---|---:|
| Total Customers | 7,043 |
| Churned Customers | 1,869 |
| Churn Rate | 26.54% |
| Average Monthly Charges | 64.76 |

## Data Analysis

The following visualizations were created in Tableau:

1. Churn Rate by Contract
2. Churn by Internet Service
3. Churn by Monthly Charges
4. Churn by Tenure
5. Churn by Payment Method
6. Churn by Gender
7. Churn by Senior Citizen
8. Churn by Partner and Dependents

## Key Findings

- The overall customer churn rate is 26.54%.
- Month-to-month contracts have the highest churn rate at 42.71%.
- One-year contracts have a churn rate of 11.27%.
- Two-year contracts have the lowest churn rate at 2.83%.
- Electronic check users account for the largest number of churned customers among the payment methods shown in the dashboard.
- The dashboard helps compare churn patterns across customer groups and service categories.

## Conclusion

The analysis shows that customers with month-to-month contracts have a much higher churn rate than customers with longer-term contracts.

The company can use these insights to improve customer retention strategies, understand customer needs, and focus on customer groups with higher churn.
